# Device Manager

A modern Android application for managing devices, built with Jetpack Compose and Room Database.

## Features
- **Modern UI**: Built entirely with Jetpack Compose for a reactive and smooth user experience.
- **Local Persistence**: Uses Room Database for efficient data storage.
- **Clean Architecture**: Follows Android best practices for scalability and maintainability.

## Tech Stack
- **Language**: Kotlin
- **UI Toolkit**: Jetpack Compose
- **Database**: Room
- **Dependency Injection**: Kapt (Configured)
- **Build System**: Gradle Kotlin DSL

## Getting Started
1. Clone the repository.
2. Open in Android Studio (Ladybug or newer).
3. Ensure JDK 17 is configured in `gradle.properties`.
4. Build and Run.
